# 欢乐掼蛋 🃏

欢乐斗地主风格的**掼蛋**网页游戏:单机(AI 陪玩)+ 局域网联机 + 公网隧道联机,无需安装,浏览器即开即玩,适配手机横屏。

## 功能特性

- 🎮 **单机模式**:你 + 3 个 AI,立即开局
- 🌐 **联机模式**:4 位房间号建房/加入,可加机器人凑局,掉线自动 AI 托管
- 📱 **移动端适配**:手机横屏完整可玩,竖屏提示旋转
- ✨ **一键组牌**:按 同花顺>炸弹>钢板>三连对>顺子 自动理牌,可还原;配合分组视图按组合竖向陈列(带牌型标签)
- 🗂 **横排/分组双视图**:分组视图同点牌竖列叠放,花色清晰可见
- 🔊 **合成音效 + 炸弹特效**:无需任何静态资源
- 📖 内置规则说明

## 完整规则实现

- 两副牌 108 张,4 人 2 队(对家结伙),从 2 升到打 A
- 牌点:大王>小王>级牌>A>K>…>3>2;**每局单一级牌**(谁升级打谁的级),红桃级牌为**逢人配**(可配除王外任意牌)
- 牌型:单张/对子/三张/三带二/顺子(5 张)/三连对/钢板(两连三张)/炸弹(4 张起)/同花顺/四大天王
- 序列牌型 2 接在 A 后:`A2345`、`AA2233`、`AAA222` 合法且最小,`KKAA22` 非法;级牌按自然位置参与
- 炸弹梯队:四大天王 > 6 张+炸 > 同花顺 > 5 张炸 > 4 张炸
- **进贡/还贡(≤10)/双大王抗贡**,贡牌全场公开;**接风**;**报牌**(≤10 张显示)
- 首出:还贡后贡牌最大者先出(单贡即末游),双下贡牌相同由头游上家先出,抗贡则头游先出
- 升级:双下 +3、头游+三游 +2、头游+末游 +1;打 A 需头游且队友非末游,三次不过回 2
- 结算页展示各家剩余手牌(斗地主式)

## 快速开始

```bash
npm install
npm start
```

- 本机:http://localhost:8080
- **同一 WiFi 联机**:朋友手机/电脑浏览器直接打开

  ```
  http://192.168.77.55:8080
  ```

  > 这是你当前在 WiFi 下的局域网 IP(`ipconfig getifaddr en0` 可查;若换了网络 IP 会变,以 `npm start` 启动日志里打印的"局域网"地址为准)。进入后点「联机模式」→ 一人「创建房间」→ 其他人输入 4 位房间号加入。

### 公网联机(临时隧道)

宽带限制较多时推荐 pinggy(标准 443 端口,免安装免注册,60 分钟有效):

```bash
ssh -p 443 -o StrictHostKeyChecking=no -R0:localhost:8080 a.pinggy.io
# 输出里 https://xxx.run.pinggy-free.link 即为公网地址
```

也可用 bore(`bore local 8080 --to bore.pub`)或 cloudflared(注意部分网络会拦 QUIC/SRV,需 `--protocol http2 --edge <ip>:7844`)。长期开黑建议部署到云服务器。

## 技术架构

纯原生实现,零前端框架、零构建步骤,唯一依赖是 `ws`:

```
shared/           # 浏览器/Node 共用核心
  rules.js        # 牌型识别(逢人配多解释)、大小比较、出牌枚举、提示
  engine.js       # 对局状态机:发牌/进贡还贡抗贡/回合/接风/升级打A/结算
  ai.js           # AI:单机陪玩 + 联机补位/托管共用
server/index.js   # 静态服务 + WebSocket 房间管理(服务器权威对局)
public/           # 前端:index.html + css + js(牌桌渲染/主控/网络/音效)
test/             # rules 47 项 + engine 5 项 + 4AI 整局模拟 + jsdom UI 冒烟 + ws 联机 e2e
```

设计要点:规则与引擎浏览器/Node 双端复用——单机在本地跑引擎,联机时同一引擎跑在服务器上保证权威性;前端只渲染状态 + 发送意图。
